# 直线电机推力与速度设计

直线电机目标模式使用“目标推力（N）”和“目标直线速度（m/s）”，不再套用旋转电机的转矩和 RPM。磁极中心距为 `τ` 时，电频率按 `f = v / (2τ)` 估算；结合实际逐圈磁链面积、气隙磁密、绕组系数及每相串联线圈数得到反电势常数，并按功率一致关系 `F = 3 K_e I相` 计算所需 RMS 相电流。

求解器同时检查直流母线利用率、热态电阻压降、电感压降、铜箔载流能力和制造约束。磁极中心距输入 0 时自动采用包含铜箔、净距、过孔和端子外伸量的防干涉间距。

该模型假设三相正弦行波磁场和均匀有效气隙磁密；端部效应、推力波动、磁钢覆盖率和完整热路径仍需仿真与样机验证。
