# 环形扇区线圈与电机目标求解

## 几何输入

环形扇区以 PCB 外径、中心开孔直径、槽数、边缘铜箔退让和槽间隔为硬边界。几何模块先计算：

1. 外、内圆中心线半径；
2. 单槽机械角与扣除槽间隔后的可用半角；
3. 外侧和内侧可用弦宽；
4. 径向与周向共同允许的最大嵌套深度；
5. 满足最小线宽/净距的最大圈数和均匀节距。

每个槽生成一条连续的嵌套环形扇区螺旋；阵列中心位于内外有效半径的中点，并按槽数均匀旋转。相邻槽可交替绕向。

## 电机目标模式

“按电压／转速／转矩设计电机”以以下顺序处理参数：

- **硬约束**：PCB 外径/内径、槽数、层数、制造最小线宽与净距、已完成步骤的锁定参数。
- **主要目标**：由每相反电势常数直接换算目标转矩所需的 RMS 相电流；因此即使目标转速为 0，非零转矩仍会产生非零电流需求。
- **电气边界**：直流母线按 SVPWM 的最大基波线电压 `Vdc/√2` 换算，叠加反电势、热态电阻压降和电感压降后，与最大相电流及铜箔温升载流上限共同校验。
- **软目标**：目标相电阻和目标相电感。

求解器枚举可制造的整数圈数，为每个候选计算线宽、净距、长度、20°C/热态相电阻、相电感、逐圈实际包围面积对应的反电动势、所需相电流、所需线电压和铜损；优先返回满足电压和电流边界的最低评分结果。没有完全可行解时，底层求解器会保留最接近候选及 `violations`，界面则阻止创建并显示所需/可用电压和电流，避免把不可行方案误标为有效。

同一电气目标求解也用于径向排列的椭圆、跑道形和梯形电机线圈。直线电机使用独立的“推力 + 直线速度”模型，并由磁极中心距计算电频率，不再套用旋转电机的“转矩 + RPM”。详见《直线电机推力与速度设计》。

径向电机阵列的安全半径按相邻线圈旋转后的支撑包络计算，并额外计入铜箔宽度、净距以及过孔/端子扇出的外伸量，避免跑道形等长轴线圈在相邻磁极处相交。

## 估算边界

当前模型是前期尺寸与电气筛选模型。相电感仍采用面积等效的平面螺旋近似，铜箔载流能力采用保守经验式；模型不包含具体磁钢形状、互感、漏磁、齿槽效应、涡流、频率相关铜损、介质损耗、驱动器压降和完整热路径。正式电机设计仍应进行磁场/热仿真和样机验证。
