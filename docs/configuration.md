# 配置与用户方案

## 文件命名

CoilForge 只使用与当前插件名称对应的配置目录和文件：

- `CoilForge/coilforge-settings.json`：当前 KiCad 版本的最近一次参数。
- `CoilForge/coilforge-profiles.json`：所有 KiCad 版本共享的命名用户方案。

不会迁移旧 `kicad_spiral_plugin/settings.json`。当前设置不存在、无法读取、JSON 损坏或字段非法时，`SettingsStore.load()` 直接返回内置默认值。

## 写入安全

设置和用户方案先写入同目录临时文件，再使用原子替换更新目标文件，以降低程序中断后留下半个 JSON 文件的风险。

## 用户方案

用户可在界面顶部输入自定义名称并保存当前完整参数组合：

- 名称最长 80 个字符，不能包含控制字符。
- 名称比较不区分大小写。
- 已存在时必须确认覆盖。
- 可加载、删除、重命名、导入和导出。
- 加载方案会解除当前流程锁定，随后按新方案重新生成场景所需步骤；不同场景不再强制固定为七步。
