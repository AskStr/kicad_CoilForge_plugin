# CoilForge 环形扇区电机设计、用户方案与架构重构

## 已确认目标
- 新增参考图风格的环形扇区电机线圈，按 PCB 外径、中心孔、极/槽数和工艺间距平均铺满可用环形区域。
- 电机模式以 PCB 尺寸、供电电压、目标转矩、目标转速、连接方式、最大相电流和允许温升为主要输入；圈数和长度改为派生结果。
- 普通线圈增加目标电阻、电感、电流/温升设计模式。
- 前序步骤点击“下一步”后成为硬约束；后续求解不得覆盖，只能提示冲突和建议返回步骤。
- 配置缺失/损坏时静默回退默认参数；配置文件使用 CoilForge 命名；不读取或迁移旧路径。
- 用户命名方案跨 KiCad 版本共享，支持保存、加载、覆盖、重命名、删除和 JSON 导入导出。
- 参数按场景动态显示隐藏，基础/高级分层。
- 实现迁入 `coilforge/` 子包，根目录保留 KiCad 必需入口和一版兼容包装器。

## 关键决策
- 电机求解输入包含目标转速、星形/三角形连接、最大相电流和允许温升。
- PCB 尺寸、板厂工艺、极槽数、连接方式和已锁定步骤为硬约束；目标转矩为主目标；电压、电流、电阻、电感按容差优化。
- 用户方案使用跨 KiCad 版本共享存储；当前会话设置仍可保留版本隔离。
- 新增 `motor_sector`，保留 `motor_trapezoid` 兼容旧配置。
- 扇形电感与温升为工程估算，界面明确提示需 DRC、热验证和场求解/实测复核。
